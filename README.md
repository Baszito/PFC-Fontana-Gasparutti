# PFC-Fontana-Gasparutti
## Proyecto final de carrera.
*Desarrollo de una plataforma inteligente para el análisis y la optimización del marketing en sitios web mediante la generación de recomendaciones orientada a pequeñas y medianas empresas*
Integrantes : Fontana Juan Pablo - Gasparutti Lucas Ariel

### Etapa 1 : fase investigativa
En esta etapa se procederá con una internalización en el tema, se busca comprender el proceso de análisis de los datos y extracción de información a partir de los mismos, con el fin de comprender los procesos a automatizar. A su vez, se seleccionarán los métodos a utilizar para dicha automatización. Por último, se realizará una primera aproximación a las conclusiones que se pueden inferir a partir de dicha información. 


### Etapa 2 : recolección y almacenamiento de los datos
Esta etapa comprende el proceso de diseño y desarrollo de un script que permita la recolección de los datos de comportamiento de usuarios necesarios para poder realizar el análisis y procesamiento especificado en el documento de investigación. A su vez, se procederá con la implementación de un servidor, al cual se enviarán dichos datos, junto con el diseño e implementación de una base de datos relacional para el correcto almacenamiento de la información.
